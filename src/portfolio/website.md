## This website!
This website itself is one of my main projects, designed and built from scratch to showcase my work and development progress.It uses a custom colorscheme with the fonts being DM Sans for normal text and IBM Plex for monoscaced text for a balanced, visually consistent aesthetic, and is built with [11ty (Eleventy)↗](https://www.11ty.dev/) using Nunjucks, Markdown, and custom CSS. The focus was on keeping the structure lightweight, modular, and easy to maintain while maintaining a clean and readable design. Check out the [repo](https://github.com/lexeep/lexeep.github.io) to see how it's built.
